# Etch-a-Sketch

A browser-based Etch-a-Sketch project built as part of [The Odin Project](https://www.theodinproject.com/lessons/foundations-etch-a-sketch) Foundations course.

## Links

- **Live Demo:** https://rawnaq-code.github.io/odin-etch-a-sketch/
- **GitHub Repository:** https://github.com/rawnaq-code/odin-etch-a-sketch

## Features

- Draw by hovering over the grid.
- Generate a new grid with a custom size (up to 100 squares per side).
- Randomize square colors when interacting with them.
- Progressive darkening effect.

- HTML

- JavaScript
